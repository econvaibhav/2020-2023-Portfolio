# Crime data: categorisation & interpretation

[← All projects](../../README.md) · [Project page](index.html)

A 62-page group project examining crime-data categories and how they are presented. It includes comparisons across Assam, Gujarat, Kerala and Punjab, word-frequency displays and colour-blind-friendly graphics, followed by a discussion of categorisation and reporting.

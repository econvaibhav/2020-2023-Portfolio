# Jharkhand PDS web scraping

[← All projects](../../README.md) · [Project page](index.html)

This notebook collects a block-level public-distribution report using Requests and BeautifulSoup, then cleans and structures the table with pandas. It covers row extraction, column naming, whitespace removal and numeric conversion. A later section explores an Excel workbook with openpyxl.

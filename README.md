# 2020–2023 Portfolio

A selection of my papers, notebooks and visual projects from 2020–2023.

[View the portfolio](https://econvaibhav.github.io/2020-2023-Portfolio/) · [Browse projects](#projects)

![The portfolio website](assets/portfolio-preview.jpg)

## Projects

| Project | Description | Files |
| --- | --- | --- |
| [Renewable energy & economic growth](projects/renewable-energy-growth/) | A cross-country study of renewable-energy investment and economic growth, using an augmented Solow model. | research paper, research summary, src presentation |
| [Health & livelihoods](projects/health-and-livelihoods/) | Household facilities and treatment expenditure, studied using NSS health data, descriptive tables and regressions. | research report, descriptive tables, regression analysis |
| [Data visualisation](projects/data-visualization/) | A colour-blind-friendly visualisation poster and a Python notebook of charts, maps and plotting experiments. | visualisation poster, notebook |
| [Jharkhand PDS web scraping](projects/public-distribution-scraping/) | A Python notebook for extracting and cleaning a public-distribution table from the Jharkhand government website. | notebook |
| [Crime data: categorisation & interpretation](projects/crime-data-categories/) | A group booklet comparing crime-data categories and visualisations for Assam, Gujarat, Kerala and Punjab. | categorisation and interpretation booklet |
| [India & China: development comparisons](projects/india-china-development/) | A two-page historical timeline and two data assignments comparing social indicators, employment and economic change. | historical timeline, social-indicator comparisons, structural-change comparisons |
| [Water-pricing replication](projects/replication-water-pricing/) | A replication report covering Tables 1–8 of a study on irrigation pricing and water conservation. | replication report |
| [Education & wages](projects/education-and-wages/) | An analysis of education and weekly earnings across employment groups, using PLFS 2018–19 data. | computational economics paper |
| [Renewable-energy finance](projects/renewable-finance-geopolitics/) | A paper comparing renewable-energy funding by region, income group and financing instrument. | renewable-finance paper |
| [Piotroski stock scoring](projects/piotroski-stock-scoring/) | A group Python notebook that retrieves company statements and calculates a Piotroski-style financial score. | notebook |
| [Carbon capture in India](projects/ccus-india/) | An illustrated presentation and report on carbon capture, utilisation and storage in Indian industry. | interdisciplinary report, visual presentation |
| [Rajasthan suicide data story](projects/rajasthan-suicide-data-story/) | A visual data story exploring reported suicide patterns in Rajasthan through comparisons, maps and literature. | visual data story |
